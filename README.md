# OmniTech

> Вебсайт магазину електроніки на Flask: головна сторінка, «Про нас», «Контакти» та «Часті питання», адаптивна верстка й темна тема.

Навчальний командний проєкт з дисципліни «Основи програмної інженерії», група ІПЗ-22. Лабораторна робота 03 «Розробка базового вебпроєкту». У наступних лабораторних цей самий проєкт отримає базу даних, каталог товарів, замовлення та API.

## Технології

- **Python 3.12+** і **Flask** — сервер і маршрути сторінок;
- **Jinja2** — шаблони сторінок із наслідуванням від спільного `base.html`;
- **Tailwind CSS 4** (через CDN) — оформлення та адаптивність без окремого CSS-файлу.

## Запуск

Команди для терміналу VS Code (Windows, PowerShell), у теці проєкту:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Сайт відкривається за адресою <http://127.0.0.1:5000>. Зупинити сервер — `Ctrl+C` у терміналі.

## Структура

```
omnitech/
├── app.py              # застосунок Flask: дані сторінок і маршрути
├── requirements.txt    # залежності (pip freeze)
├── templates/
│   ├── base.html       # спільний каркас: меню, футер, Tailwind, перемикач теми
│   ├── home.html       # Головна
│   ├── about.html      # Про нас
│   ├── contacts.html   # Контакти
│   └── faq.html        # Часті питання
└── lab-reports/        # звіти учасників команди
```

## Сторінки

| Адреса | Сторінка | Що на ній |
|---|---|---|
| `/` | Головна | банер, переваги магазину, популярні товари (список з `app.py`) |
| `/about` | Про нас | історія магазину, цінності, команда проєкту |
| `/contacts` | Контакти | адреса, телефон, email, графік роботи (словник з `app.py`), карта |
| `/faq` | Часті питання | питання й відповіді, що розгортаються по кліку (список з `app.py`) |
